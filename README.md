# Painel — Pesquisadores Populares Interseccionais em Ciência, Bioeconomia e Inovação Digital

Painel de acompanhamento dos grupos territoriais do curso **Pesquisadores Populares Interseccionais em Ciência, Bioeconomia e Inovação Digital** —
Projeto Saúde Planetária e Inovação Sociotécnica para Territórios Saudáveis, Sustentáveis e Solidários no DF (Fiocruz Brasília / CTIS).

Os dados exibidos são pessoais e estão **cifrados** (AES-256-GCM). O acesso requer senha, disponível apenas para a coordenação e os monitores territoriais.
